# NAME.md — variorum

- **Nombre:** `variorum`
- **Prefijo:** *(ninguno — nombre propio, marca independiente)*
- **Idioma:** latín
- **Significado:** Abreviatura de *editio cum notis variorum* — la edición que conserva todas las variantes de un texto y registra quién propuso cada una. No es la versión «correcta»: es la que hace visible el conjunto.
- **Por qué:** un estándar de versionado no debe declarar qué versión es la buena, sino conservar la identidad, el linaje y el estado de cada artefacto. Eso es exactamente lo que hace un variorum.
